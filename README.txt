KINGS ROBLOX - تحديث الواجهة

المحتويات:
- index.html: الصفحة الرئيسية والأقسام وواجهة الشات التجريبية.
- manifest.webmanifest و icon.svg و sw.js: ملفات تثبيت التطبيق وتحديثه.

مهم: الشات الحالي تجريبي ومحلي على نفس الجهاز والمتصفح فقط. لا توجد مزامنة بين الأعضاء. لجعل الشات عامًا ومباشرًا، يجب ربطه بخدمة خلفية آمنة مع تسجيل دخول وإشراف وبلاغات.

طريقة النشر:
1. ارفع ملف ZIP إلى Netlify كعملية Deploy جديدة، أو اسحب المجلد بعد فك الضغط إلى صفحة النشر.
2. بعد اكتمال النشر افتح رابط الموقع ثم حدّث الصفحة. قد تحتاج إغلاق التطبيق وإعادة فتحه لتحديث ملفات PWA.
